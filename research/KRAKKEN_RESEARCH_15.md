# Krakken research 15 — compact probability certificates and all-direction derivative bounds

**26 November 2026 update:** §§15.9–15.11 add fixed-difference population ceilings and an exact 21-dimensional-family census. Original 25 November results and evidence remain intact.

25 November 2026. This ledger follows the 22 November revision of [Research 14](KRAKKEN_RESEARCH_14.md), including §14.12. H159 denotes the entire set of 159-byte messages. H_r(m) is the first 256 bits of the state obtained by the original indexed r-round permutation on the padded H159 block. In particular, H_8 is the public 256-bit hash on this domain. The byte at index 159 is 0x86, followed by 96 zero capacity bytes. Byte and bit indices are zero-based, with the least significant bit first within a byte.

Two new studies were completed on the original scalar and AVX2 sources. The first uses small independent random coefficient files to sample large four-wise independent message families; the second exhausts a fixed, ordinary 12-dimensional H159 affine family. Neither conditions on minimum first-round activity. No solver, random-permutation assumption, independence of S-box transitions, or cryptographic security estimate is used in these concrete-function results. The random study has an explicit uniform-random-coefficient assumption; the deterministic study does not.

## 15.1 — Source-pinned compact probability experiment

### Design and retained data

Before generating the seed, [DESIGN.md](reproduce/research15/DESIGN.md) specified eight independent maps, each with n = 2^20 input indices, and joint reporting ceilings C < 2^-36 and p_max < 2^-18.5 for the first 64 output bits of H_8 on uniform H159. Every map must contain no repeated prefix. All maps are retained; none is rejected because of its rank, outputs, or observed collision count. The model is that the coefficient bytes from the OS are independent and uniform. The saved seed was obtained from `/dev/urandom`; this operational source is not itself a mathematical proof of perfect randomness.

The target distribution is the digest of an independently uniform H159 message. The generated messages within a map are **four-wise independent**, not jointly independent. The proof below is specific to that sampling construction; it does not apply the independent-sample Poisson bound from Research 14 to dependent data.

### Four-wise independent H159 samples with 6,519 bytes per map

Let F = GF(2^20) with polynomial basis and reduction polynomial X^20 + X^3 + 1. The implementation verifies the full 1,048,575-element nonzero cycle generated by X. In the quotient ring this shows every nonzero element is a power of a unit, so the quotient is a field.

For x in F define the binary feature vector

    f(x) = (1, bits_20(x), bits_20(x^3)) in GF(2)^41.

**Lemma.** Any at most four distinct feature rows are linearly independent over GF(2).

An odd-sized subset cannot sum to zero because the first coordinate is 1. For two distinct rows the x coordinates cannot sum to zero. If four distinct elements a,b,c,d give zero sum, then d = a+b+c. In characteristic two,

    a^3 + b^3 + c^3 + (a+b+c)^3 = (a+b)(a+c)(b+c).

The right-hand side is nonzero because a,b,c are distinct in a field. This contradicts zero sum in the cubic coordinates. These exhaust all nonempty subsets of at most four rows.

Choose 41 independent uniform vectors V_j in GF(2)^1272. Set

    M(x) = XOR_{j : f(x)_j = 1} V_j.

For any k≤4 distinct indices, the k feature rows have rank k. For each of the 1272 message bit positions the linear map from the 41 independent uniform coefficient bits to the k output bits is onto. Each k-tuple of output bits therefore has exactly 2^(41−k) preimages. Independence across bit positions then gives k independent uniform H159 messages. This proves four-wise independence without an assumption about the hash. Uniform messages may coincide; a repeated message necessarily gives a repeated prefix and would fail the test.

Eight independent coefficient arrays use only 8·41·159 = 52,152 random bytes to specify 8,388,608 hash evaluations. The retained seed and the generator specify all message bytes, not merely a pseudorandom generator initialized with a short seed. The seed's SHA-256 is `f5436bebe426c800335e772eef6ffc4e2c1b016126ed83a64ba1882d2304a1d9`.

## 15.2 — Collision probability from a four-wise independent no-repeat experiment

Write Y for the first 64 bits of H_8(M) when M is uniform on H159, p_y for its distribution, C = Σ_y p_y², and T = Σ_y p_y³. For one map let Z count unordered pairs of distinct indices whose prefix values agree. Four-wise independence of messages implies four-wise independence of the corresponding deterministic digest projections. In particular,

    E[Z] = B C,     B = n(n−1)/2.

Two different pair indicators are independent if their index pairs are disjoint. If they share one index, their joint expectation is T, because the three involved digests are independent. There are n(n−1)(n−2) ordered pairs of distinct unordered pairs sharing one index. Hence the exact variance is

    Var(Z) = B(C−C²) + n(n−1)(n−2)(T−C²).

Since max_y p_y ≤ sqrt(C), one has T ≤ C^(3/2). Thus

    Var(Z) ≤ V(C) = B C + n(n−1)(n−2) C^(3/2).

Cantelli's one-sided variance inequality says that for a random variable with mean μ and variance σ², Pr[Z−μ ≤ −a] ≤ σ²/(σ²+a²) for a>0. With μ=BC, Z=0 implies an undershoot of μ, so

    Pr[Z=0] ≤ V(C) / (V(C) + B² C²).

The right-hand side decreases with C>0: the ratio V(C)/(B²C²) is a positive sum of terms proportional to C^-1 and C^-1/2. At the predeclared threshold C_0=2^-36 and n=2^20,

    μ_0 = 7.999992370605469,
    V(C_0) = 71.99980926525313,
    q_0 = V(C_0)/(V(C_0)+μ_0²) < 0.529412.

The maps are independently sampled. If C≥C_0, the probability of all eight maps passing is at most q_0^8 < **0.006171**. This is a bound on the probability of falsely issuing the collision-probability claim. It does not count the pairs of indices as independent trials. It includes collisions from repeated input messages.

## 15.3 — Stronger point-probability bound from the same maps

Suppose a fixed prefix value has mass p≥p_0=2^-18.5. In one map let K count observations equal to that value. Its mean μ=np and variance np(1−p)≤μ follow already from pairwise independence. If the map contains no repeated prefix then K≤1. For μ>1, Cantelli gives

    Pr[K≤1] ≤ μ/(μ+(μ−1)^2).

The expression decreases for μ>1. At the threshold μ_0=2^1.5. A conservative rational lower bound is μ_0>2.8284. In the predeclared experiment, if any prefix mass exceeds the threshold (including equality), fix one such prefix before the maps are drawn. Passing all maps requires K≤1 on each map for that particular value. Independence of maps therefore gives false-pass probability below **0.001947**. No union over the 2^64 possible prefix values is required: the null hypothesis asserts that at least one violating value exists, and a passing panel necessarily passes for any fixed violating value.

By a union bound the probability of falsely issuing either of the two population ceilings under their common reporting rule is at most 0.008117280 (rounded upward). The joint frequentist coverage is therefore **greater than 99.188%**. The checker evaluates the collision expression with exact rational arithmetic, and uses the rational 2.8284 bound for the point expression. This confidence statement is not a posterior probability that Krakken is secure.

### Consequences for the full 256-bit digest

Let p'_h denote the distribution of the full 256-bit digest of a uniform H159 message. Refining the prefix buckets cannot increase the sum of squared probabilities or the maximum bucket mass. Thus, with the joint confidence stated above,

    Σ_h (p'_h)^2 < 2^-36,     max_h p'_h < 2^-18.5.

Equivalently, H_2(H_8(M)) > 36 bits and H_infinity(H_8(M)) > 18.5 bits. The collision entropy improvement over the 30.5-bit Research 14 estimate is 5.5 bits; the two upper bounds differ by a factor 2^5.5 ≈ 45.25. This compares certified ceilings, not measured collision probabilities. The actual collision probability may be far smaller than either ceiling.

## 15.4 — Further consequences: target lists, random search, differences and message selection

Every result in this section is a consequence of the same statistical certificate, so no additional confidence budget is needed. Let M,N be independent uniform H159 messages and let C'=Σ_h (p'_h)^2. For every full 256-bit XOR target b, Cauchy–Schwarz gives

    Pr[H_8(M) XOR H_8(N)=b] = Σ_h p'_h p'_(h XOR b) ≤ C' < 2^-36.

Consequently, for a fixed list of L distinct XOR targets, the total success probability is < min(1,L·2^-36) whenever L·2^-36≤1 (otherwise use the trivial ceiling 1). The same applies to a predictor selecting from a fixed table of L targets; the success event lies within membership of that table, even if the selector sees more information. This is a bound for independent uniform bases, not for pairs produced by an arbitrary adaptive algorithm.

Define P_d(b)=Pr_M[H_8(M) XOR H_8(M XOR d)=b] on the entire H159 domain. The change of variables (M,N) ↔ (M,d=M XOR N) is bijective. Thus

    E_{d uniform over GF(2)^1272}[P_d(b)] < 2^-36.

For each prescribed b and integer k≤36, the fraction of differences d for which P_d(b)≥2^-k is <2^(k−36), by Markov's inequality. For example, fewer than a fraction 2^-20 of differences can give a probability ≥2^-16 for a specified b. This holds for every b simultaneously because the same C' bounds all XOR targets. The exceptional sets can be different for different b. In particular this does not give a bound on max_d P_d(0) for nonzero d. Excluding the zero difference from the average changes the bound by at most the factor 1/(1−2^-1272); for b=0 its exact contribution can instead be subtracted.

For q independent uniform messages the probability of a repeated full digest, even including repeated messages, is at most binom(q,2)·2^-36, capped at one. At q=2^17, this bound is below 1/8. The confidence level describes the uncertainty of the population estimate; 1/8 describes a fresh experiment conditional on the asserted ceiling holding. This is **not** a 17-bit or 36-bit attack-work lower bound.

For any fixed set A of H159 messages of uniform mass α>0, and independently drawn M,N uniform on A, conditional digest masses satisfy p'_(h|A)≤p'_h/α. Consequently

    Pr[H_8(M)=H_8(N) | both drawn uniformly on A] < 2^-36/α²,
    max_h Pr[H_8(M)=h | M uniform on A] < 2^-18.5/α,

with trivial ceilings of one when necessary. More generally for independent uniform draws from fixed sets A,B of masses α,β, respectively, the XOR-target probability is bounded by 2^-36/(αβ). These inequalities apply simultaneously to all such sets; they follow by restricting the original independent pair event and dividing by the conditioning mass. For example every affine message slice of codimension two has α=1/4 and collision probability <2^-32 for independent uniform draws inside that slice. They do not apply to correlated pairs chosen to exploit a differential, or to deliberate selection of individual favorable messages.

## 15.5 — Deterministic all-direction derivative degree bounds

### Fixed ordinary H159 family

Use the following message embedding of GF(2)^12, chosen before evaluation:

    m_x[0]   = x & 63
    m_x[158] = x >> 6
    m_x[i]   = 0 for 1≤i≤157.

All 4096 messages are valid H159. This is a linear family in message coordinates, and the actual padded-state family is affine. It is not one of the conditioned five-call sets. It lies in the endpoint-byte grid of Research 14 §14.7 but varies only the low six bits of each endpoint byte. Let F_r(x)=H_r(m_x).

For every nonzero 12-bit index offset e, define D_(r,e)(x)=F_r(x) XOR F_r(x XOR e). This derivative is invariant under x↦x XOR e. Choose p to be the highest set bit of e. Exactly one member of each unordered pair {x,x XOR e} has x_p=0. The 11-bit quotient parameter u encodes all the other coordinates, in increasing bit order. Explicitly insert a zero at bit p to obtain x(u). Write G_(r,e)(u)=D_(r,e)(x(u)).

**Theorem (R15-ALLDIR-DEG-004).** For each r in {2,8}, every e≠0 in the 12-bit index space, and every nonzero 256-bit output mask β, the Boolean function β·G_(r,e)(u) has algebraic degree at least **seven**.

In particular for every such e, with d=m_e the corresponding H159 XOR difference, the full-domain function

    m ↦ β·(H_r(m) XOR H_r(m XOR d))

has algebraic degree at least seven on the entire H159 message space. There is no polynomial of degree ≤6 on the message bits that predicts this derivative parity **perfectly for every base message**. In particular these 4095 nonzero directions are not linear structures for any nonzero digest parity. For each such direction and parity, both derivative values occur even on this small family. The theorem does not quantify the largest bias or exclude good approximate predictors.

### Proof by simultaneous coefficient rank

Write the vector Boolean algebraic normal form of G as

    G(u) = XOR_{S subset of {0,...,10}} a_S · product_{j in S} u_j,

where a_S is a 256-bit coefficient vector, and the product is a bit. The coefficient a_S is computed exactly by XORing the values indexed by every subset of S. Equivalently apply the standard Boolean Möbius transform in place, using XOR additions. The 562 coefficients with |S|≥7 are obtained for each offset and depth. For every one of the 8190 cases, their binary span has rank **256**. If a nonzero β gave a component of degree ≤6, then β would annihilate every one of these 562 vectors, contrary to rank 256. This proves the theorem simultaneously for all 2^256−1 nonzero masks without enumerating them. Substitution of the affine map u↦m_x(u) cannot increase Boolean algebraic degree; hence the full-domain derivative also has degree at least seven.

For a fixed e, the quotient is just a coordinate restriction of the full derivative. The upper limit on what this particular rank method can establish on an 11-bit quotient is degree seven for every nonzero mask: only 232 monomials have degree ≥8, fewer than 256 output coordinates. A stronger degree result uniform over all masks would require a larger quotient or additional witnesses. The existing global eight-round digest-component degree≥20 theorem is not replaced by this result; it does not, by itself, imply a degree floor for every first derivative.

### Independent affine-graph check

For every depth and offset, form the 2048 binary rows

    (1, u_0,...,u_10, G_(r,e)(u)_0,...,G_(r,e)(u)_255).

Each has 268 coordinates. The computed rank is **268** for every case. This supplies a separate certificate excluding any exact relation β·G(u)=a·u XOR c with β≠0, and even any nonzero affine relation in the joint graph coordinates. In the 12-bit unreduced parametrization the relation D(x)=D(x XOR e) remains, so the proof uses the quotient; it does not claim independent variation of all original 12 coordinates in the chosen representative set.

## 15.6 — Exact all-pair census on the same family

For each r in {2,8}, the 4096 actual first-64-bit digest prefixes are distinct. The original design additionally required that every nonzero offset have 2048 distinct nonzero 64-bit derivative prefixes on the quotient. All cases passed. A separate post-design census then enumerated **all unordered pairs** x<y on the same already selected family, not just a single offset. For each depth all 8,386,560 prefix XORs were distinct and nonzero.

| Depth | Offsets checked | Largest zero or repeat count in any quotient | Minimum degree-≥7 coefficient rank | Minimum affine graph rank | Distinct nonzero unordered-pair prefix XORs |
|---:|---:|---:|---:|---:|---:|
| 2 | 4095 | 0 | 256 / 256 | 268 / 268 | 8,386,560 / 8,386,560 |
| 8 | 4095 | 0 | 256 / 256 | 268 / 268 | 8,386,560 / 8,386,560 |

The all-pair census uses the actual 64-bit XOR, not a randomized fingerprint. Distinctness at 64 bits implies distinctness of the complete 256-bit XOR. Thus the projected output sets are Sidon sets in the XOR group, with the following exact consequences for this family, at each of the two depths:

* The digest is injective on all 4096 messages.
* No four distinct messages in the family have full digest XOR zero, even if their input offsets differ.
* For every nonzero in-family offset e and every full target b, the probability over a uniform base x in the family that D_(r,e)(x)=b is either zero or exactly 2/4096=2^-11. The zero target is never attained. The maximum is exactly 2^-11 for every e, because the two orientations of each unordered pair necessarily have equal derivative.
* When the unordered input pair is uniform among all distinct pairs, its digest XOR is uniform on exactly 8,386,560 distinct nonzero values. Its min-entropy and collision entropy both equal log2(8,386,560). For independent uniform ordered indices with replacement, zero has probability 1/4096 and each attained nonzero full target has probability 2/4096²=2^-23.

This is the smallest possible nonzero per-offset probability on a 4096-element XOR-closed family. Research 08 already certified a **larger 13-dimensional** Sidon family at eight rounds; the present 12-dimensional census is not a record for family size. It is a distinct endpoint-bit family, includes two-round results, and accompanies the new all-direction degree and graph certificates. No extrapolation of these finite-family probabilities to all H159 is justified.

### Evidence and independent checks

The original GCC AVX2 collector generated both digest depths for every family message. Clang AVX2 and GCC scalar independently recomputed all **8192** 256-bit digest values and matched every byte. Every collector also compared the extracted eight-round digest against its own public hash API for all 4096 messages. The archive [cube.bin](reproduce/research15/cube.bin) contains interleaved R2/R8 full digest bytes, increasing message index, 262,144 bytes, SHA-256 `62d2ec1f4d29c860525c44a6597438cb1278053d700a7fc31fc9fa51fbd624d0`.

The C verifier compares prefix keys directly in an open-addressed table, resolves table-slot collisions by full 64-bit key equality, performs a vector Möbius transform, and obtains rank by binary Gaussian elimination. It retains all per-offset counts and ranks in [census.txt](reproduce/research15/census.txt). Full rank is sufficient to terminate a rank computation early. A separately written Python verifier used arbitrary-precision integer elimination and a separately expressed Möbius transform on twelve fixed offsets per depth, and agreed on all 24 rank checks. It additionally generated and sorted all unordered pair-prefix XORs at both depths, independently establishing the global all-pair property. The complete C rank panel has not been rerun with the Python verifier. The post-design all-pair commitments and exact numerical confidence checks are in [checks.txt](reproduce/research15/checks.txt).

## 15.7 — Sponge-model interpretation and what remains open

The original source specifies a 2048-bit permutation, rate 1280 bits, capacity 768 bits, and a 256-bit digest in these experiments. The random-permutation sponge theorem of Bertoni, Daemen, Peeters and Van Assche is already a conditional mathematical basis for reasoning about this construction; see Research 14's comparison and Research 02's restricted-block model discussion. The generic classical birthday scale for 256-bit random-oracle outputs is 2^128, and the capacity-related ideal-sponge scale is 2^384. These scales refer to an ideal-permutation model and its assumptions, not a proof that the concrete Krakken permutation has no faster structural attack. See [On the Indifferentiability of the Sponge Construction](https://keccak.team/files/SpongeIndifferentiability.pdf).

The new evidence concerns two particular aspects of that instantiation: a sharper statistical ceiling for the actual eight-round uniform-H159 digest distribution, and the absence of low-degree exact derivative predictors for all directions of a selected subspace. It does not establish the full eight-round concrete permutation's indifferentiability from a random oracle, 128-bit adversarial collision resistance, or 256-bit preimage resistance. Neither the previous sequential-counter hunter nor the present compact random sampling constitutes an exhaustive test at the generic birthday scale. No value of the tested-message count should be interpreted as a direct security-work exponent.

In particular, the universal activity floors from Research 11–12 (16 unrestricted, 20 H159, 22 H159 conditioned on A1=5) are **unchanged**. The new derivative theorem excludes perfect low-degree relations in a subset of directions, but does not supply a worst-case eight-round differential probability or settle the outstanding low-activity exclusions. Statistical collision entropy, differential point probability, exact Boolean degree, and computational attack cost remain distinct quantities.

Promising next steps are to extend the all-direction degree certificate to a 13- or 14-bit endpoint-spanning family, to derive source-specific degree/linear-structure exclusions for low-activity classified differences, and to investigate rigorous bounds for fixed chosen differences beyond the presently enumerated populations. Repeating independent compact-map experiments at larger n would strengthen the statistical entropy certificate but still not settle a worst-case collision attack. No such additional experiments are claimed here.

## 15.9 — Eight fixed-difference probability bounds on the entire H159 domain (26 November 2026)

This addendum retains §§15.1–15.8 and their original evidence. Unlike the averaged-difference result in §15.4, the new population experiment fixes a nonzero input difference before sampling the base message. Unlike the deterministic census in §15.6, the population bounds below apply to uniform bases on **all** H159, not merely on an enumerated subspace. The eight specified differences are not asserted to be the 21 minimum-activity families of Research 12. A separate deterministic census in §15.10 gives an exact probability on much smaller, precisely specified affine families. Neither investigation introduces a generic random-permutation assumption.

### Addendum result board

| ID | Quantity and scope | Result | Evidence class |
|---|---|---|---|
| R15-FIXDP-007 | Maximum eight-round full digest XOR point probability for each of eight specified fixed differences, uniform H159 base | < 2^-16.5 | Joint confidence > 99.10% with next two rows |
| R15-FIXZERO-008 | Probability of a full eight-round digest collision within a related pair, same differences and population | < 2^-17.5 | Same joint certificate |
| R15-FIXC-009 | Matching full digest differences of two independently drawn base pairs with the same specified offset | < 2^-32 | Same joint certificate |

The statistical thresholds are ceilings, not measured probabilities or cryptographic attack-work bounds. The exact grid theorem has no sampling-confidence qualification, but its population is the grid only.

### Fixed input differences and sampling design

Define G_d(m) = H_8(m) XOR H_8(m XOR d), and Y_d(m) = first64(G_d(m)). Here d is a fixed 159-byte XOR offset, and m is uniform over all H159. We study the distribution p_d(y) of Y_d(M), its maximum point mass p_d,max, its zero mass p_d(0), and its collision probability C_d = sum_y p_d(y)^2. Byte numbering starts at zero; unlisted offset bytes are zero.

| ID | Nonzero offset bytes | Hamming weight in bits |
|---:|---|---:|
| 0 | byte 0 = 01 | 1 |
| 1 | byte 79 = 01 | 1 |

### Proof of the simultaneous confidence certificate

For a fixed d and one map let Z be the number of unordered index pairs whose 64-bit derivative prefixes agree. From four-wise independence, the derivation of §15.2 applies unchanged with Y_d replacing the ordinary digest prefix. With B=n(n−1)/2 and C=C_d,

    E[Z] = B C,
    Var(Z) = B(C−C²) + n(n−1)(n−2)(sum_y p_d(y)^3−C²)
           ≤ V(C) = BC+n(n−1)(n−2)C^(3/2).

Cantelli gives Pr[Z=0] ≤ V(C)/(V(C)+B²C²). As in §15.2, this expression decreases in C. If C_d≥2^-32, substitute that threshold and n=2^18. Independence of the eight maps bounds the probability of all eight passing by **0.006170833854** (decimal rounded). Thus the collision-probability assertion is issued only when every difference and every map passes.

For any fixed target y of mass p, let K count its occurrences within a map. Pairwise independence gives E[K]=np=μ and Var(K)=np(1−p)≤μ. The no-repeat condition implies K≤1. For μ>1 Cantelli yields

    Pr[K≤1] ≤ μ/(μ+(μ−1)^2).

If p≥2^-16.5 then μ≥sqrt(8)>2.8284. The expression decreases with μ>1. Across eight maps, false passage for any such fixed violating target has probability at most **0.001946394403** (rounded).

For the specific zero prefix, require K=0 in every map. Cantelli now gives Pr[K=0]≤1/(1+μ). At p_d(0)≥2^-17.5, μ≥sqrt(2)>1.4142. Using this conservative rational lower bound gives an eight-map false-pass ceiling of **0.000866590723** (rounded).

For each of these three global assertions, if it is false, fix a violating d, and where relevant a violating target y, independently of the sampled maps. Passing the full panel implies passing for that fixed violation. No independence between different d is needed, and no union factor for the number of target values or differences is needed for this all-pass reporting rule. Union-bounding the three types of false report gives a total error below 0.008983819 and hence joint coverage **greater than 99.1016%**. The exact rational calculations are in [bounds.py](reproduce/research15_fixed_diff/bounds.py) and [bounds.txt](reproduce/research15_fixed_diff/bounds.txt). This confidence is frequentist under the coefficient assumption, not a posterior probability of security. It is a new certificate separate from the §15.3 confidence statement.

    max_b Pr_M[G_d(M)=b] < 2^-16.5,

## 15.10 — Exact 20-bit-base, 21-dimensional-family differential census

After the statistical study, [GRID_DESIGN.md](reproduce/research15_fixed_diff/GRID_DESIGN.md) specified a separate deterministic experiment. Let F be the 20-dimensional linear subspace of H159 consisting of messages

    m_x[40] = x & 255,
    m_x[80] = (x >> 8) & 255,
    m_x[120] = x >> 16,

The low nibble of byte 120 varies and its high nibble is zero. Every d in §15.9 has a nonzero bit outside these 20 coordinates, hence d is not in F. Define E_d = F + span{d} = F union (F XOR d), a 21-dimensional linear family. The two cosets are disjoint. For each fixed d, evaluate G_d on every m_x in F. This is a complete census, not a statistical sample. The eight different E_d need not be disjoint from each other, and the proof is separate for each d.

**Theorem (exact differential distribution).** For each listed d and uniform M on E_d, the full 256-bit eight-round digest XOR G_d(M) assumes exactly 2^20 distinct nonzero values, each with probability exactly 2^-20. In particular its maximum differential probability is exactly **2^-20**, and its zero-target probability is exactly zero.

**Proof.** Because d is not in F, each unordered pair {m_x,m_x XOR d} is represented exactly once by x. The eight-round permutation/hash evaluation and prefix census show that the 2^20 values Y_d(m_x) are distinct and nonzero. The full G_d(m_x) are consequently also distinct and nonzero. For M in F XOR d, the equality G_d(m XOR d)=G_d(m) follows by exchanging the two members of the XOR. Each attained target therefore has exactly two preimages in the 2^21-element E_d, proving the theorem. The result is equally true for uniform M on F alone. No probability assumption about the hash, rounds, S-box calls, or source of x is used.

**Corollaries.** On each E_d, the full derivative has collision entropy and min-entropy exactly 20 bits; independently chosen uniform bases produce matching full differences with probability exactly 2^-20. A fixed list of ell targets succeeds with probability at most min(1,ell/2^20). No four distinct messages consisting of two different d-pairs wholly in E_d have zero digest quartet XOR. The restriction to the same d is necessary; this is not a Sidon theorem for every direction or an exclusion of all quartets. It gives a larger restricted fixed-direction probability certificate than the 12-dimensional all-direction family of §15.6, while §15.6 retains its stronger quantifier over all nonzero directions in its own family. The populations differ, so the numerical probabilities should not be represented as a universal improvement of Krakken's differential probability.

The [grid results](reproduce/research15_fixed_diff/grid_results.txt) retain counts and per-direction commitments. Neither a 64-bit fingerprint of a digest difference nor a probabilistic hash-table slot collision is used to establish equality: the observed 64 bits are themselves compared. ### Simultaneous confidence calculation

For a fixed case (d or P), let Y be the first 64 bits of its derivative on uniform H159, p_y its distribution, C=sum_y p_y^2 and n=65,536. Let p_max=max_y p_y and p_0=Pr[Y=0]. The joint reporting rule requires no repeated values and no zero values in every specified case. For any particular fixed case the sample consists of n independent draws of Y, because anchors are independently uniform and the derivative is a fixed deterministic function of each anchor. Dependence between cases is immaterial. Three distribution-free false-pass bounds follow.

1. **Point ceiling.** If any mass p≥2^-13, its count is Binomial(n,p). The probability of at most one occurrence decreases in p, so at the threshold p*=2^-13, it is at most

       (1-p*)^n + n p* (1-p*)^(n-1)
       ≤ (1+n p*/(1-p*)) exp(-n p*) < 0.003019491293.

   Here n p*=8. A no-repeat test cannot pass if the count exceeds one.

2. **Zero ceiling.** If p_0≥2^-13.5, its no-hit probability is at most exp(-n p_0)≤exp(-sqrt(32))<exp(-5.65)<0.003517516776.

3. **Collision-probability ceiling.** Use the Poissonized no-repeat inequality of Research 14 §14.2 with independent Poisson count K of mean lambda=0.95 n. For completeness, for h(x)=x-ln(1+x), independent Poisson bucket counts give no-repeat probability exp(-sum_y h(lambda p_y)). Since h(x)/x^2 decreases on positive x and p_y≤sqrt(C), this is at most (1+t)exp(-t) for t=lambda sqrt(C). Monotonicity in the number of draws then gives

       Pr[no repeat in n draws] ≤ (1+t)exp(-t)/Pr[K≤n].

   The Poisson upper-tail exponential bound of Research 14 gives Pr[K>n]≤exp(-n (0.05)^2/2)=exp(-81.92). If C≥2^-25.5, t≥0.95*2^3.25>9. Since (1+t)exp(-t) decreases, a conservative false-pass bound is 10 exp(-9)/(1-exp(-9))<0.001234250361.

For each of the three global ceilings, if it is false on the fixed panel, fix one violating case and target (if applicable) independently of the sample. Passing the entire panel implies passing that case. Thus there is no factor of 255, 651, or 2^64 in these bounds: this is an all-pass reporting rule for the global maximum, not a collection of individual tests issuing arbitrary subsets of conclusions. Union-bound the three false-report probabilities. [bounds.py](reproduce/research15_subspace/bounds.py) uses conservative exact rational upper bounds for exp(-x), reciprocals of finite Taylor sums with positive terms, and verifies the inequalities for the irrational thresholds by squaring or taking fourth powers. The sum is below 0.007771258426, rounded upward in the stored computation; joint coverage exceeds 99.22%. The same calculation is valid for the primary 255-case rule, the fixed secondary 651-case rule alone, or the fixed combined 906-case rule; the secondary analysis was added after the primary results, and the confidence claim is for this particular fixed combined rule, not for unrestricted selection of further panels after seeing data. No extra independence is inferred by reusing anchors. There is no joint confidence claim with all other research ledgers or adaptive future experiments.

## 15.13 — Exact first-order probability for 255 directions on one common grid

Define F as the 18-dimensional H159 linear space generated by W and the ten distinct unit bits consisting of all eight bits of byte 70 and bits 0 and 1 of byte 71. All other bits are zero. The index x from 0 to 2^18−1 denotes its unique message: low eight bits select W, next eight bits specify byte 70, and last two bits specify byte 71. In particular W is a subspace of F, and x XOR d denotes translation by the corresponding input difference. This grid and all directions were fixed before seed generation, independently of the population observations.

Compute the complete 256-bit H_8 digest at each of the 262,144 grid messages. The ordered digest archive has SHA-256 `23e6450f921b61cc040961c286597f9ce411fd1992d94dfb072d3ce0063dabd7`; GCC and Clang AVX2 generated the same full byte stream. For each of the 255 nonzero d in W, take the 131,072 unordered d-pairs, choosing the unique representative x with x<x XOR d. Compute and compare the actual first 64 bits of G_d on every representative. All were distinct and nonzero within each direction. There were 33,423,360 representative derivative evaluations, made from the one precomputed digest array, rather than that many independent hash evaluations. Per-direction exact counts and commitments are stored in [results.txt](reproduce/research15_subspace/results.txt).

**Theorem R15-GRID-DP-013.** For every nonzero d in W, with M uniform over F, the complete eight-round digest derivative has exactly 2^17 attainable values, each of probability 2^-17, and zero is not attainable. Consequently its exact maximum differential probability is 2^-17 and both its min-entropy and collision entropy are exactly 17 bits. The same probability conclusion holds for the full-state derivative on F.

**Proof.** G_d is constant on each two-element coset of span(d): exchanging the two messages leaves their XOR unchanged. All 2^17 such cosets have distinct nonzero first-64-bit XORs by the census. Distinct projected values force distinct full-digest and full-state values; nonzero projected values force nonzero full values. The cosets have equal size and partition F. Each therefore has probability 2/2^18. The resulting distribution is uniform on exactly 2^17 points, proving all claims. This is the minimum possible maximum DP for any function on this grid for that d, since the derivative is constant on each coset. Any two distinct d-pairs in F have unequal digest differences. In particular no zero quartet XOR is possible if its four distinct messages form two d-pairs in F for one of these d. This is not an all-direction Sidon theorem for F because directions in F outside W were not enumerated.

## 15.14 — Exact second-order probability for every plane in a six-dimensional direction space

For each of the 651 planes P contained in U, examine the quotient F/P. There are exactly 2^16 cosets, each with four messages. Select the smallest integer index among x, x XOR d, x XOR e, x XOR d XOR e, where d,e form any basis of P. Compare the first 64 bits of Q_P from the same grid digest array, for every such representative. Every plane passed: 65,536 distinct nonzero values in every case, covering 42,663,936 representative quartet XORs. Plane identifiers are the sorted triples of their nonzero elements, so each plane is enumerated exactly once. The census code compares actual prefix integers, not their hash commitments.

**Theorem R15-GRID-QDP-014.** For every plane P contained in U, with M uniform over F, the full digest quartet XOR Q_P(M) has exactly 2^16 attainable values, each of probability 2^-16. Zero is impossible. Its exact maximum second-order differential probability is 2^-16; both min-entropy and collision entropy are 16 bits. The same distributional cardinality and point probability hold for the full-state four-message XOR.

**Proof.** Q_P is invariant under translation by any element of P because translation permutes the four summands. It is thus constant on each coset of P. The exact census establishes distinct nonzero projected outputs for all these cosets. The corresponding full-digest and full-state outputs are therefore distinct and nonzero as well. Each coset contains four uniformly weighted messages, giving probability 4/2^18=2^-16. This is optimal for any function on F for that plane in the same coset sense as the previous theorem. In particular two different cosets of a fixed P cannot have the same four-message XOR; this does not assert cross-plane uniqueness. The second-order theorem addresses a prescribed four-message relation and not an arbitrary collection of four or eight inputs.

Completed checks:

* GCC 14.2 and Clang 17.0 AVX2 independently compiled the same original C. The complete 262,144-message grid digest streams matched on all 256 bits. The first 256 uniform anchors, for all 256 shifts (65,536 digests), also matched on their first 64 bits.
* The first four sample anchors and every shift (1,024 full digests) matched between the original scalar and GCC AVX2 API. A Python integer-based reconstruction of the offsets independently evaluated those 1,024 scalar digests and compared their actual 64-bit prefixes with the main sample stream. The same reconstruction checked 128 fixed grid indices against the full scalar digest. Its separate scalar audit commitments match the C audit streams. Full scalar population and grid replays were not performed.
* Independent Python sets and visited-coset enumeration reproduced the exact counts for four named first-order offsets and four named planes on the deterministic grid, and direct integer sets reproduced four offsets and four planes on the sample. The complete main counts are obtained by exact uint64 sorting and direct adjacency comparison. SHA-256 is used only to commit to the data order, not as a probabilistic equality surrogate.
* The full new replay script was executed successfully a second time, regenerating the complete grid and both population panels from the original C and retained sample, and matching all per-case count/commitment rows and the rational confidence output. This is local reproducibility, not independent external peer review.

The full ordered sample prefix stream (anchor order, then shift indices 0,...,255, little-endian uint64) has SHA-256 `21af0310fc27ecdb7ac83d603b3f8247a65832ba83c20aa6c5196aed681ea4da`. The complete streams are not stored in the ZIP because the sample bytes and grid coordinates regenerate them. The evidence files themselves are pinned in `SHA256SUMS`.

Extract the complete updated ZIP and run from its root on little-endian x86 with AVX2, GCC, Clang, Python 3, NumPy, bash and coreutils:

```bash
bash reproduce/research15_subspace/replay.sh
# Optional lower concurrency:
SERIAL=1 bash reproduce/research15_subspace/replay.sh
```

This replay checks manifests, compiles original sources, regenerates the data, compares exact archived results, and runs the audit and confidence checker. It uses temporary files, approximately 150 MiB of disk and several hundred MiB of available RAM, with four concurrent collectors by default. No GFNI, VAES, AVX-512, AES-NI, solver, external download or resampling is required by the AVX2 replay. Scalar compilation uses `-march=native` for the local machine. The earlier replay instructions remain in §§15.8 and 15.11. The primary sample is not claimed to be a set of 16.8 million IID messages; the inference uses 65,536 independent anchors under the OS-random sampling assumption. The post-primary panel is explicitly documented and shares those anchors.

This study broadens the number of examined directions and gives exact optimal probabilities for a common grid and all planes in a prescribed subspace. Stronger numerical probability ceilings for the particular eight differences of §15.9 remain separate. A universal full-domain bound, a worst-case chosen-base bound, and any adversarial collision-security exponent remain open. GitHub and all cryptographic source implementations have been left unchanged.
